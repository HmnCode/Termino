# 📚 برنامه کلاسی دانشگاه

برنامه کلاسی با تقویم شمسی، هفته‌های زوج/فرد، حالت تاریک و کار آفلاین.

## امکانات
- تقویم شمسی تعاملی
- ثبت کلاس با تایم ثابت و متغیر
- شمارش معکوس تا کلاس بعدی
- حالت تاریک/روشن
- نصب PWA روی گوشی
- کار کامل آفلاین

## نصب روی گوشی
1. آدرس Pages رو باز کن
2. دکمه «نصب» رو بزن
3. از هوم‌اسکرین بازش کن
